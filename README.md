# BizTrust Agentic Engineer Team Guide

Enterprise-grade implementation guide for a governed AI engineering team delivering BizTrust from architecture contract through production operations.

## Preview

Open `index.html` directly, or serve the repository with any static web server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Repository contents

- `index.html` — complete implementation guide
- `styles.css` — responsive brand design system
- `script.js` — navigation, search, theme, progress and copy controls
- `assets/` — supplied UniTrust brand marks

## Publishing

The site is compatible with GitHub Pages. In repository settings, configure Pages to deploy from the root of the `main` branch.

## Governance

The guide treats `BIZTRUST-WP-ARCH-001A` as the contract-freeze work package and prevents implementation from beginning until architecture and authority gates have passed.
